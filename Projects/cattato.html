Unity is a popular game engine used for developing 2D and 3D games, mostly used for indie game development and my personal favorite. Cattato is a school project inspired by games like Brotato and Vampire Survivors, games that created or defined a new genre of games called Survivors-like or Bullet Heaven, where the player has to survive waves of enemies while collecting loot and upgrades to become stronger.

This was a super short project and the idea was to practice spawning enemies, creating a loot system and a simple upgrade system. The game was made in Unity using C# scripts and assets created by members of the development team. Due to the short time frame, the games was not really polished and finished (it's playable), but it was a fun experience and a good practice although i would like to improve it in the future.

The main challenge was to organize and manage the team, since we were all working on different parts of the game and we had to make sure that everything was working together, and that we were all on the same page.
